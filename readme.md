## 📌 Project Overview

GymVerse is a comprehensive web-based fitness platform that connects **Gym Owners**, **Fitness Trainers**, and **Regular Users** under a single digital ecosystem. It eliminates manual record-keeping, provides online course creation, enables real-time chat, and offers secure QR-based gym entry verification.

## FrontEnd URL: https://gym-verse-zeta.vercel.app/
## Backend URL: https://gymverse-i1xo.onrender.com/

## 👥 Target Users

| Role | Description | Key Features |
|------|-------------|--------------|
| **User** | Fitness enthusiasts | Find gyms, buy memberships, watch courses, follow trainers, read blogs |
| **Trainer** | Fitness professionals | Create courses, write blogs, apply to gyms, get job offers, view ratings |
| **Owner** | Gym business owners | Manage gyms, set pricing, verify QR, hire trainers, track revenue |

---

## ✨ Key Features

### For Users
- 🔍 Find nearby gyms with interactive maps
- 💳 Buy memberships using Razorpay
- 🎬 Watch video courses with full player controls
- 📝 Read & interact with fitness blogs
- 👨‍🏫 Follow trainers and view their content
- 💬 Real-time chat with trainers
- ⭐ Rate and review gyms, courses, and trainers

### For Trainers
- 📹 Create and sell video courses
- ✍️ Write and publish fitness blogs
- 📊 View students, followers, and earnings
- 🏢 Apply to gyms for jobs
- 📨 Receive and respond to hiring requests
- ⭐ See ratings and reviews from users

### For Gym Owners
- 🏋️ Create and manage multiple gyms
- 💰 Set custom membership prices (Monthly/Quarterly/Yearly)
- 👥 View all active members
- ✅ Approve or reject trainer applications
- 📤 Send hiring requests to trainers
- 🔐 Verify member entry using QR codes
- 📈 Track monthly revenue and members
